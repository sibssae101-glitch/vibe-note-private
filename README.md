# 바이브 노트 — 개인판

한 일 · 쓴 기준 · 결정한 것 · 해야 할 거를 날마다 한 줄씩 적는 노트입니다.
공개판(예시만 들어 있는 `vibe-note`)과 화면이 같고, **저장 위치만 다릅니다.**

주소: <https://sibssae101-glitch.github.io/vibe-note-private/>

## 열면 바로 — 로그인 없음

1. 주소를 엽니다. **끝.** 일정 탭이 바로 뜨고 그 자리에서 적을 수 있습니다.
2. 저장 버튼은 없습니다 — 고치면 몇 초 뒤 알아서 저장됩니다.
3. 기본 저장 위치는 **이 기기**(브라우저 localStorage)입니다. 맨 위 얇은 한 줄
   `이 기기에만 저장 중` 이 그 상태를 알리고, 그 줄을 누르면 설정이 열립니다.

로그인·모드 선택·첫 화면 안내는 없습니다. 어떤 기능도 연결 없이 그대로 동작합니다
(3탭·S펜·받아쓰기·녹음·브리핑 배지·좁은 폭 즉시 입력).

## 구글 드라이브로도 (선택)

설정(톱니) → **구글 계정으로 연결** 한 번이면, 그다음부터는 기록이 **내 구글 드라이브 한 파일**에
저장되고 폰이든 PC든 같은 기록이 보입니다. 다른 사람은 볼 수 없습니다. 서버는 없습니다.

연결하면 **이 기기에 있던 기록이 드라이브 파일과 합쳐집니다** — 수정 시각이 새로운 쪽을 쓰고,
진 쪽 사본은 드라이브에 `바이브노트-백업-YYYYMMDD-HHMM.json` 으로 남깁니다(아래 동기화 규칙 그대로).
연결하지 않은 동안에는 **외부로 나가는 요청이 한 번도 없습니다** — 구글 로그인 스크립트도
연결을 누를 때만 받아 옵니다.

## 메모의 목소리 — 받아쓰기와 녹음

- **받아쓰기(🎤)**: 메모 편집기 아래 버튼을 누르면 말한 것이 커서 자리에 글로 들어갑니다. 다시 누르면 멈춥니다.
  중간 결과는 보여 주기만 하고, 확정된 문장만 본문에 남겨 바로 저장합니다. 언어는 한국어(ko-KR) 고정.
  마이크 권한은 **버튼을 누를 때만** 묻고, 거부되면 안내 한 줄만 남습니다(화면은 그대로 쓸 수 있습니다).
  브라우저의 음성인식(Web Speech API)을 쓰므로 **오디오는 브라우저 제조사 서버로 갑니다** — 이 페이지는 저장하지 않습니다.
- **녹음(●)**: 누르면 녹음, 다시 누르면 정지. 끝나면 메모 아래 재생 카드가 붙고 한 메모에 여러 개 붙일 수 있습니다.
  한 건에 10분·20MB 까지이며 넘으면 조용히 멈추고 알립니다. 이 기기에만 쓰는 동안에는 소리가
  **이 기기(IndexedDB)** 에만 남고, 연결하면 밀린 녹음이 드라이브로 올라갑니다.

## 파일로 옮기기 — 내보내기 / 가져오기

설정 안쪽의 작은 두 버튼입니다. 기기 사이를 손으로 옮기는 최소한의 통로입니다.

- **파일로 내보내기**: 지금 기록을 `바이브노트-내보내기-YYYYMMDD-HHMM.json` 한 파일로 내려받습니다.
  다섯 키가 그대로 들어가고, **오디오 본체는 담지 않습니다**(메모의 파일명·길이 같은 메타만).
- **파일에서 가져오기**: 파일을 고르면 무엇이 들어오는지 한 줄로 보여 주고, 확인을 눌러야 덮어씁니다.
  병합하지 않습니다. 덮어쓰기 전 값은 이 기기의 `vnp-backup-before-import-v1` 에 남깁니다.

## 기록이 사는 곳

- **이 기기에만(기본)**: `vnp-mirror-v1` 하나에 다섯 키를 함께 담습니다 —
  `vn-entries-v1`(일정) · `vn-briefings-v1`(브리핑) · `vn-briefing-checks-v1`(브리핑 체크) ·
  `vn-notes-v1`(메모·손글씨) · `vn-theme`(밝게/어둡게).
- **구글에 연결한 뒤**: 드라이브의 앱 전용 폴더 `vibe-note/` 안 **`바이브노트.json` 한 파일**.
  녹음 본체는 같은 폴더 아래 `vibe-note/audio/YYYYMMDD-HHMMSS.webm`(아이폰은 `.m4a`).
- 소리는 어느 쪽이든 **localStorage 에 절대 쓰지 않습니다.** 기기 사본은 IndexedDB(`vibe-note-audio`).
- 스코프는 `https://www.googleapis.com/auth/drive.file` **하나뿐**입니다. 이 앱이 만들거나 연 파일 말고는
  드라이브의 다른 어떤 파일도 볼 수 없습니다.

## 동기화 규칙 (연결한 뒤)

- 열 때 드라이브에서 읽어 그리고, 고치면 2.5초 뒤 저장합니다.
- 저장이 안 되면(오프라인·오류) **이 기기에 남겨 두고** 화면 위에 한 줄로 알립니다. 다음 접속 때 밀린 변경을 올립니다.
- 두 곳이 같은 파일을 고쳤으면 **수정 시각이 새로운 쪽**을 쓰고, 밀려난 쪽 사본을 드라이브에
  `바이브노트-백업-YYYYMMDD-HHMM.json` 으로 남긴 뒤 조용히 알립니다.
- 기기 값(테마, 이 기기 사본)은 기기마다 따로 둡니다. 액세스 토큰은 메모리에만 있고 저장소에 남기지 않습니다.
- 설정의 **로그아웃**은 다시 `이 기기에만` 으로 돌아갑니다. 기기에 있는 기록은 그대로 남습니다.

## 연결에 필요한 것 — 구글 OAuth 클라이언트 ID

브라우저에서 드라이브를 읽고 쓰려면 이 페이지의 OAuth 클라이언트 ID 가 있어야 합니다.
(클라이언트 ID 는 비밀이 아닙니다. 비밀 키는 이 페이지에 없습니다.)

1. <https://console.cloud.google.com> — 프로젝트를 하나 만들고 (계정에 2단계 인증이 켜져 있어야 합니다)
2. **API 및 서비스 → 라이브러리**에서 *Google Drive API* 를 사용 설정
3. **OAuth 동의 화면**: 외부(External), 앱 이름·지원 이메일·개발자 이메일만 채워 저장
4. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션**
   승인된 JavaScript 원본: `https://sibssae101-glitch.github.io`
5. 만들어진 클라이언트 ID(`…apps.googleusercontent.com`)를 복사
6. 이 페이지의 **설정(톱니) → 클라이언트 ID** 칸에 붙여 넣고 저장

여러 사람이 각자 계정으로 쓰게 하려면 OAuth 동의 화면을 **게시**해야 합니다(테스트 상태에서는
등록한 테스트 사용자만 연결됩니다). 저장된 값은 그 브라우저에만 남습니다.
